## 数据来源与可重算性说明

1. 本目录的 CSV 来源于历史审计修复过程，由仓库根目录的 `audit_recompute.py` 重新计算生成。
2. `audit_recompute.py` 的输入是本地 `output/` 目录（每日 `竞彩分析_<date>.csv`、`竞彩足球_<date>.csv`、`每日记录_<date>.json` 等）。
3. `output/` 属于运行产物，当前被 `.gitignore` 排除，不在 Git 仓库内。
4. 因此：**A 组数据可用于结果复核与结论追溯，但不能保证在一份全新 clone 中从头完整重算**。若需重算，需先补齐本地 `output/` 历史数据。
5. `audit_recompute.py` 使用修复后的各 tracker `build_row` 重建数据，并与根目录原始表逐条比对生成差异表，故 A 组与根目录同名表存在差异属预期行为。
